## 项目概述
基于Ansys瞬态结构仿真的隧道衬砌振动加速度信号数据增强。目标：以有限仿真工况数据为原料，开展数据增强，为后续ML代理模型训练提供大规模数据支撑。

## 仿真模型构建（详见模型构建设置.docx）
- **求解器**：瞬态结构分析
- **模型组成**：围岩(G3)、初衬(C25)、二衬(C30)、道床(C40)、轨道板(C40)、填充物(C40)、枕木序列(C40)、传感器(不锈钢)
- **边界条件**：围岩五面固定+吸波边界(APDL)；初衬弹性支撑+吸波边界；全局重力；键合接触为主，枕木-轨道板用增广拉格朗日+非线性控制；传感器与内衬键合半径0.02-0.03m
- **步数控制**：Step1=2.0s（重力加载，20-40子步）；Step2=2.0-2.05s（动态激励，时间步1e-4s，最小1e-6s）
- **阻尼**：质量系数3.7，刚度系数2e-5
- **列车参数**：车速60km/h(16.667m/s)，枕木中心距600mm，相邻枕木时差0.036s

## 传感器布设与编号逻辑
- **总数**：700个传感器，分布在二衬内表面
- **排布**：7排(A-G)，每排分左右两侧，每侧50个传感器，纵向间隔1m
- **排命名**：SensorsFaceA ~ SensorsFaceG，从隧道入口外侧面朝隧道"从上到下"
- **环向间距**：将衬砌截面展平后，14个传感器（7排×左右2侧）沿环向排列形成13个间距，不属于某排而是属于整个截面。环向排列顺序为：右边墙 → G右 → F右 → E右 → D右 → C右 → B右 → A右 → A左 → B左 → C左 → D左 → E左 → F左 → G左 → 左边墙。13个传感器间距为（从右到左）：G右-F右:0.97, F右-E右:0.97, E右-D右:1, D右-C右:1, C右-B右:1.2, B右-A右:1.3, A右-A左:1.5, A左-B左:1.3, B左-C左:1.2, C左-D左:1.0, D左-E左:1.0, E左-F左:0.97, F左-G左:0.97 (m)。关于A右-A左(1.5m，拱顶处最大)呈对称分布——从拱顶A排向下间距递减，到G排最小0.97m。两端还有G排传感器到边墙的距离0.4m，即完整间距序列含15个值：(右边墙-左边墙),0.4m,0.97m，0.97m，1m，1m，1.2m，1.3m，1.5m，1.3m，1.2m，1m，1m，0.97m，0.97m,0.4m
- **编号规则**：
  - A排：左1-50，右101-150
  - B排：左201-250，右301-350
  - C排：左401-450，右501-550
  - D排：左601-650，右701-750
  - E排：左801-850，右901-950
  - F排：左1001-1050，右1101-1150
  - G排：左1201-1250，右1301-1350
  - 规律：百位=排序号(1-7)×2-1(左)/×2(右)，个位十位=纵向01-50
  - 51-100号段空缺（左侧50个后直接跳到右侧101起）

## CSV数据结构
- **编码**：GB2312
- **文件命名**：
  - 健康模型(Solid)：FaceAccelS_X.csv (X=A~G)
  - 脱空模型(Void)：FaceAccel_X.csv (X=A~G)
- **列结构**：
  - 第1列：行号(unnamed)
  - 第2列：步骤(1=重力加载，2=动态激励)
  - 第3列：时间[s] (0.1~2.05)
  - 第4列起：100个探针的总体加速度(m/s²)，格式`[Excel列号] Face_Accel_Probe_NNN  (总体) [m/s?]`
- **行数**：976行；Step1=39行(0.1~2.0s, 纯重力, 数据全零)；Step2=937行(2.0~2.05s, dt≈1e-4s, 有振动数据)
- **数据量级**：Step2非零值范围约[2e-6, 0.1] m/s²，均值约0.02 m/s²
- **每个CSV**：100个探针×937个时间步 = 一个工况一排的数据矩阵

## 工况与脱空参数
- **命名格式**：Void.角度.直径，如Void.13.180 = 从右侧水平面逆时针旋转13°处，二衬直径180mm半球形脱空
- **Solid**：健康无脱空对照
- **脱空位置**：均在第25号传感器截面(即各排编号尾号25的传感器)


## 技术备忘
- CSV编码：GB2312（pandas读取需指定encoding='gb2312'）
- 数据有效区域：仅需Step2（2.0~2.05s），Step1为纯重力加载阶段数据全零
- 项目路径：VoidDataset\

## 脱空建模方式
- **角度确定**：在轨道板表面中点绘制水平射线，以该中点为旋转中心旋转对应的角度
- **位置确定**：将旋转后的射线与二衬外表面的交点定为半球形脱空的球心（注意二衬的截面形状并非规则的圆形，具体形状和参数详见“隧道截面图纸.png”）
- **脱空确定**：基于上一步的球心绘制特定直径的球，然后将二衬中与该球形相交的部分挖去
